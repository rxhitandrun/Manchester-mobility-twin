# Manchester Mobility Twin

Prototype multimodal mobility digital twin of Manchester's Oxford Road corridor using SUMO and Python/TraCI to study disruption propagation and recovery across buses, bicycles, and general traffic.

## Project status
Early-stage prototype.

## Planned components
- SUMO network model
- Python/TraCI data interface
- Multimodal traffic scenarios
- Disruption scenarios
- Recovery analysis
- Results and visualisations
